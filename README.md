# Disc Graphics

A browser-based generative drawing tool for creating radial field compositions with concentric shapes, contours, hatch fills, and animated threshold effects.

## Features

- Interactive p5.js canvas with live controls
- Shape layers including lines, dots, dashes, waves, crosshatch, concentric circles, contour flow, and radial rays
- Breakup fields including Perlin, radial, angular, ripple, spiral, Voronoi, turbulence, moire, cracks, superformula, and more
- Randomize All controls for fast visual exploration
- SVG, animated SVG, WebM, and PNG export options

## Usage

Open `index.html` in a browser and adjust the controls in the sidebar.

The app runs entirely client-side and loads p5.js from jsDelivr.
